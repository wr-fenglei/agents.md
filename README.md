## 用词标准

- 不用 "捋顺", "落下去", "看得清, 点得到", "跑得通, 用得顺" 这类比喻或口号式表达, 直接说明事实, 目标, 行动或验收要求
- 用有依据的数值或具体影响代替 "非常", "特别", "极其", "十分", "较", "稍微", "略微", "更", "最", "明显", "显著", "大幅", "强大", "成熟", "靠谱" 等模糊修饰和评价, 没有依据就删去相关描述
- 陈述并列要点时, 不连续套用 ".. 怎样 ..", ".. 由谁 .." 这类问句结构, 直接说出对应的内容
- 不用 "在当今...", "下面我们来看看..." 这类泛泛开场和预告
- 不用 "真正重要的是...", "不是...而是...", "不只是...而是..." 这类模板化强调, 对比, 空过渡和修辞性总结

## 标点格式

- 中文用英文标点, 逗号连接相关分句, 冒号引出解释和清单
- 段末不加标点, 段中句末用逗号代替句号

## 配置与技能维护

- 维护 AGENTS.md 或技能前, 先读取 Codex 配置目录中的 `skill-maintenance.md`, 配置目录由 `CODEX_HOME` 指定, 未设置时使用 `~/.codex`
- 产品会话发现配置或技能问题时, 按本地记录转交负责会话, 附上问题, 具体案例和预期结果, 不在产品会话直接维护
- 负责会话先核实来源, 再读取并修改源文件, 按记录同步安装副本和仓库, 来源或位置变化后同步更新记录
- 记录缺失或负责会话不可用时先核实, 不猜测会话, 路径或仓库, 不把安装目录或插件缓存默认当作维护源, 未建立或未知的仓库如实注明
- 本机路径, 会话标识和仓库对应关系只写入本地维护记录, 不提交公开规则仓库

本规则也须遵守以上要求, 新增内容优先合并到已有章节
